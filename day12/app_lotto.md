# PRD: 로또 번호 생성기 (app_lotto)

## 1. 개요

| 항목 | 내용 |
| --- | --- |
| 제품명 | 로또 번호 생성기 |
| 목적 | 사용자가 고정 번호와 제외 번호를 지정하고, 버튼 한 번으로 로또 번호 5세트를 랜덤 생성·복사할 수 있는 웹 앱 |
| 기술 스택 | HTML5, CSS3, Vanilla JavaScript (ES6+), Bootstrap 5 (CDN) |
| 실행 환경 | 최신 데스크톱/모바일 브라우저 (Chrome, Edge, Safari, Firefox), 별도 서버 없이 `index.html` 직접 실행 가능 |
| 범위 제외 | 지난 회차 당첨번호 조회, 결과 저장(로컬 스토리지/서버), 로그인 |

## 2. 파일 구조

HTML, CSS, JS는 반드시 분리한다.

```
day12/
├── index.html          # 마크업 (Bootstrap CDN 로드)
├── css/
│   └── style.css       # 커스텀 스타일 (로또 공, 번호판, 상태 색상)
└── js/
    └── app.js          # 상태 관리, 번호판 렌더링, 생성 로직, 복사 기능
```

- `index.html`에서 Bootstrap CSS → `css/style.css` 순서로 로드
- `index.html` 하단에서 Bootstrap JS 번들 → `js/app.js` 순서로 로드 (`app.js`는 `defer` 또는 `</body>` 직전)
- 인라인 `style`, 인라인 `onclick` 사용 금지 (이벤트는 `app.js`에서 `addEventListener`로 연결)

### CDN

```html
<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
<link href="https://cdn.jsdelivr.net/npm/bootstrap-icons@1.11.3/font/bootstrap-icons.min.css" rel="stylesheet">
<script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
```

### 3.1 헤더
- Bootstrap `navbar` 사용, 앱 이름 "로또 번호 생성기" + 클로버 아이콘(`bi-clover` 없으면 `bi-stars` 등 대체)

### 3.2 번호 선택 영역 (좌우 분할)
- Bootstrap 그리드: `<div class="row g-3">` 안에 `<div class="col-md-6">` 2개
  - 768px 이상: 좌(고정) / 우(제외) 나란히
  - 768px 미만: 위(고정) / 아래(제외) 세로로 쌓임
- 각 패널은 Bootstrap `card`
  - 고정 번호 패널: 상단 테두리 파란색 강조 (`border-top` 3px, primary)
  - 제외 번호 패널: 상단 테두리 빨간색 강조 (`border-top` 3px, danger)
- 패널 헤더: 제목 + 아이콘, 선택 개수 표시(`0/5`, `0/39`), 초기화 버튼(지우개 아이콘)
- 패널 본문: 1~45 번호 버튼, CSS Grid 7열
- 패널 하단 안내 문구
  - 고정: "모든 세트에 포함돼요"
  - 제외: "어떤 세트에도 나오지 않아요"

### 3.3 생성 버튼
- 전체 너비 큰 버튼 (`btn btn-primary btn-lg w-100`), 아이콘 + "5세트 생성"

### 3.4 생성 결과 영역
- Bootstrap `card`
- 헤더: "생성 결과" 제목 + 우측 "전체 복사" 버튼 (`btn btn-outline-secondary btn-sm`)
- 본문: A~E 5개 행, 각 행 구성
  1. 세트 라벨 (A, B, C, D, E)
  2. 로또 공 6개 (오름차순 정렬)
  3. 유형 라벨: 고정 번호가 1개 이상이면 "반자동", 없으면 "자동"
  4. 세트별 "복사" 버튼 (행 오른쪽 끝, `btn btn-outline-secondary btn-sm`)
- 최초 진입 시: "5세트 생성 버튼을 눌러 번호를 만들어 보세요" 안내 문구 표시, 전체 복사 버튼 숨김 또는 비활성

## 6. JS 설계 (`js/app.js`)

### 6.1 상태
```js
const state = {
  fixed: new Set(),     // 고정 번호
  excluded: new Set(),  // 제외 번호
  results: [],          // [[n,n,n,n,n,n], ...] 5세트
};

const MAX_FIXED = 5;
const MAX_EXCLUDED = 39;
const SET_COUNT = 5;
const SET_LABELS = ['A', 'B', 'C', 'D', 'E'];
```

### 6.2 함수 목록

| 함수 | 역할 |
| --- | --- |
| `init()` | 번호판 렌더링, 이벤트 바인딩 (`DOMContentLoaded`) |
| `renderBoards()` | 고정/제외 번호판 45개 버튼을 상태에 맞게 다시 그림 (클래스, disabled, 카운트) |
| `toggleNumber(type, num)` | `type`은 `'fixed'` 또는 `'excluded'`. 제한 검사 후 Set에 추가/삭제, `renderBoards()` 호출 |
| `resetBoard(type)` | 해당 Set 비우고 다시 그림 |
| `randomInt(max)` | 0 ~ max-1 정수 반환 (`crypto.getRandomValues` 사용) |
| `generateSet()` | 고정 번호 + 풀에서 랜덤 추출로 6개 배열 생성, 오름차순 정렬 |
| `generateAll()` | 검증 후 `generateSet()` 5회 호출, `state.results` 갱신, `renderResults()` 호출 |
| `renderResults()` | 결과 카드 본문 다시 그림 (라벨, 공, 유형, 복사 버튼) |
| `getBallClass(num)` | 번호 범위에 맞는 공 색상 클래스 반환 |
| `formatSet(arr)` | `"3, 14, 22, 27, 35, 42"` 형식 문자열 |
| `copyText(text, button)` | 클립보드 복사 + 폴백 + 버튼 피드백 |
| `showToast(message)` | Bootstrap 토스트 표시 |

### 6.3 이벤트 처리
- 번호판은 이벤트 위임: 각 번호판 컨테이너에 클릭 리스너 1개, `event.target.closest('.num-btn')`의 `data-num`으로 처리
- 결과 영역도 이벤트 위임: `.copy-btn`의 `data-index`로 세트 식별
- 다시 그릴 때 `innerHTML`을 쓰면 버튼 리스너가 사라지므로, 이벤트는 컨테이너에만 단다

### 6.4 생성 알고리즘
```
pool = [1..45] − fixed − excluded
need = 6 − fixed.size
picked = pool에서 Fisher–Yates 셔플 후 앞에서 need개
set = [...fixed, ...picked].sort((a, b) => a - b)
```

## 8. 접근성
- 번호 버튼은 `<button type="button">` 사용, 선택 상태는 `aria-pressed="true|false"`
- 초기화 버튼(아이콘만): `aria-label="고정 번호 초기화"` / `"제외 번호 초기화"`
- 세트 복사 버튼: `aria-label="A 세트 복사"`
- 결과 영역에 `aria-live="polite"` 지정해 생성 결과를 스크린리더에 알림
- 키보드만으로 모든 기능 사용 가능 (Tab 이동, Enter/Space 선택)

## 9. 수용 기준 (테스트 체크리스트)

- [ ] `index.html`을 더블클릭(`file://`)으로 열어도 모든 기능이 동작한다

- [ ] 제외 10개 선택 후 생성을 여러 번 반복해도 제외 번호가 한 번도 나오지 않는다
- [ ] 고정에서 고른 번호는 제외판에서 비활성, 그 반대도 동일
- [ ] 제외 39개 선택 후에도 생성이 정상 동작 (남은 6개로 5세트 모두 동일 세트)
- [ ] 제외 40번째 선택 시 선택되지 않고 경고 토스트 표시
- [ ] 각 초기화 버튼이 해당 판만 초기화한다
- [ ] 세트별 복사 시 `n, n, n, n, n, n` 형식으로 복사되고 버튼이 1.5초간 "복사됨"으로 바뀐다
- [ ] 전체 복사 시 `A: ...` ~ `E: ...` 5줄이 복사된다
- [ ] 생성 버튼을 다시 누르면 결과가 새로 바뀌고, 새 결과의 복사 버튼도 정상 동작한다
- [ ] 모바일 폭(375px)에서 번호판이 위아래로 쌓이고 가로 스크롤이 없다
- [ ] 브라우저 콘솔에 에러가 없다
